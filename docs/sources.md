# Sources

The status of every external source the site and the template kit cite, and how each was checked. [`PROGRESS.md`](../PROGRESS.md) holds the working state; the log is in [`progress-log.md`](progress-log.md).

## How to use this file

1. **Before citing a source, find its row in the registry.** If it was last checked within 30 days and you need nothing beyond its status, cite it from the row ("current as of" the month of the last check) without checking again.
2. **Otherwise, check the landing page** (or the primary page named in the row): the current version, date, what it supersedes, and any newer draft, revision or planning note. Read only the sections you cite.
3. **After checking, update the row** (status and last checked), and add a dated note at the top of [Verification notes](#verification-notes) naming the row or PR, what you read (sections, tables) and what you decided not to cite. To see what earlier rows read, search the notes for the source ID (for example `SP 800-161`); do not read the whole section.
4. **A source you could not verify is not cited.** Write `<!-- TODO(verify): what and why -->` on the page and add it to Open questions in `PROGRESS.md`.

## How to check sources

- **Source sweeps:** subagents overflow on whole NIST PDFs. Ask for narrow checks (landing page for status, one quote per item), five to seven items per agent, and reply under 350 words. An agent reporting only "no rescission found" is not verification: use TODO(verify).
- **Checking sources directly:** eCFR pages block scripts, but its API works with compression: `curl --compressed "https://www.ecfr.gov/api/versioner/v1/full/<date>/title-5.xml?part=731&section=731.106"` returns the current text, and `.../versions/title-5.json?part=...&section=...` gives the amendment dates; WebFetch works on `https://www.ecfr.gov/api/renderer/v1/content/enhanced/current/title-41?section=201-1.201`. CISA titles revoked directives "(Revoked)" on their own pages (BOD 22-01), so a directive page without that mark supports citing it as in effect, "as of" the month.
- **Reading PDFs:** the Read tool can read a small PDF (FIPS 199 worked) but not one over 10 pages without a PDF tool, and WebFetch cannot parse PDFs (it saves the file, which `pdftotext` can then read). `pdftotext` is on the path in Git Bash; extract once, then grep for the section you need. Table columns can interleave in the extracted text (SP 800-61 Rev. 3), so cite such rows by category.
- Several NIST publications changed in 2026 (SP 800-18 Rev. 2, SP 800-70 Rev. 5, SP 800-63-4, SP 800-61 Rev. 3). Check every citation against csrc.nist.gov before writing it.
