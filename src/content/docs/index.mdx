## About

This guide is a research project directed by **Kristopher Stone, CISSP**, an AI security lead working on federal systems. It began as a test of Claude Opus 5.5, Anthropic's model, which writes most, if not all, of the content. Kristopher sets the scope, makes the decisions, and reviews and merges every change; pages marked draft are not yet reviewed. It is an ongoing work in progress, built on NIST publications, and is not an official NIST or government product. [Read how the guide is made](/about/#how-this-guide-is-made).
