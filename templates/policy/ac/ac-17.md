:::guidance
The [remote access standard](/templates/standards/remote-access-standard/) is where the CISO documents the usage restrictions, configuration and connection requirements and implementation guidance for each allowed method (AC-17a), along with the AC-17(1) to AC-17(4) requirements. Each system's security plan records which of those methods the system owner has authorized (AC-17b).
:::

- The {{org:ciso}} shall establish and document usage restrictions, configuration and connection requirements, and implementation guidance for each type of remote access allowed. (AC-17a)
- The {{org:system-owner}} shall authorize each type of remote access to the system before allowing such connections. (AC-17b)
