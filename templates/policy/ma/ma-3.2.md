control: ma-3.2
title: 'Inspect media'
status: draft
stage: operate
---

:::guidance
Scan the media on a workstation that is not connected to the system, with the organization's malicious code protection (SI-3), and record the scan in the maintenance log. NIST's discussion of this enhancement has malicious code found on the media handled as an incident.
:::

- The {{org:system-owner}} shall ensure media containing diagnostic and test programs are checked for malicious code before the media are used in the system. (MA-3(2))
- Personnel shall report malicious code found on such media as a security incident under the incident response plan (IR-6), and the media shall not be used. (MA-3(2))
