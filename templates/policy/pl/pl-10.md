:::guidance
Pick the baseline from the system's security categorization: SP 800-53B defines Low, Moderate and High security baselines and a Privacy baseline. Record the choice, and any overlay applied, in the system security plan (PL-2a.11).
:::

- Each {{org:system-owner}} shall select a control baseline for the system, based on its security categorization, and record the selection in the system security plan. (PL-10)
- A system that processes personally identifiable information shall also apply the privacy control baseline. (PL-10)

:::federal
Federal systems select the SP 800-53B security baseline that matches the system's impact level: the highest impact level for confidentiality, integrity and availability under [FIPS 199](https://csrc.nist.gov/pubs/fips/199/final), as [FIPS 200](https://csrc.nist.gov/pubs/fips/200/final) specifies.

- The {{org:system-owner}} shall select the baseline that matches the system's FIPS 199 impact level. (PL-10)

:::
