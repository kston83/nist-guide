title: 'Mobile code'
status: draft
stage: core
---

:::guidance
Mobile code is software sent from a remote system and run on a local one, such as JavaScript, macros in office documents and browser plug-ins. Define what is acceptable by technology, for example signed macros only and no browser plug-ins, and enforce it through browser and office application settings.
:::

- The {{org:ciso}} shall define acceptable and unacceptable mobile code and mobile code technologies. (SC-18a)
- The {{org:system-owner}} shall authorize, monitor and control the use of mobile code within the system. (SC-18b)
