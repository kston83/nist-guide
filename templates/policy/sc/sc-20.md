:::guidance
In practice this is DNSSEC signing for the zones the organization publishes, often a setting at the managed DNS provider. [NIST SP 800-81 Rev. 3](https://csrc.nist.gov/pubs/sp/800/81/r3/final), Secure Domain Name System (DNS) Deployment Guide (March 2026), is the NIST guide to deploying DNS securely, including DNSSEC.
:::

- The {{org:system-owner}} shall ensure the system provides additional data origin authentication and integrity verification artifacts along with the authoritative name resolution data it returns in response to external name and address resolution queries. (SC-20a)
- When the system operates as part of a distributed, hierarchical namespace, the {{org:system-owner}} shall ensure it provides the means to indicate the security status of child zones and, if a child supports secure resolution services, to enable verification of a chain of trust among parent and child domains. (SC-20b)
