:::guidance
Security functions include access enforcement, authentication, audit and cryptographic key management. Isolation is usually provided by the operating system, hypervisor or cloud platform and by running security services on dedicated components. SC-3 is in the High baseline.
:::

- The {{org:system-owner}} shall ensure the system isolates security functions from nonsecurity functions. (SC-3)
