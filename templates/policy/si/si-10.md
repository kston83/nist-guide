typical:
  si-10_odp: 'all inputs from users, external systems and interfaces, including web forms, API requests, file uploads and query parameters'
---

:::guidance
Validate on the server, against an allow list of expected type, length, format and range, and keep data separate from commands (for example, parameterized database queries). Code review and application security testing (SA-11) are where assessors look for evidence.
:::

- The {{org:system-owner}} shall ensure the system checks the validity of {{param:si-10_odp}}. (SI-10)
